# Release Notes — v0.1.0-alpha

## Português

**Título:** `Pré-Sessão v0.1.0-alpha — Organize sua sessão`

Chegou a primeira versão experimental do Pré-Sessão, uma ferramenta simples para organizar pensamentos antes da psicoterapia, sem login nem armazenamento remoto de respostas.

**Destaques:** questionários de primeira sessão e preparação semanal (incluindo modo rápido); perguntas opcionais; revisão, edição, ordem e privacidade por resposta; prévia local e salvamento em PDF pela impressão do navegador; temas claro e escuro; tutorial guiado; página de privacidade; GitHub Pages automatizado.

**Importante:** o PDF é salvo pela opção **Imprimir → Salvar como PDF** do navegador, não por download direto. Não há envio automático. Os rascunhos são apagados ao atualizar ou fechar a página. Esta versão destina-se a testes com **dados fictícios**, seguida de revisão por profissionais da psicologia.

## English

**Title:** `Pré-Sessão v0.1.0-alpha — Organize Your Session`

The first experimental release of Pré-Sessão is here: a private, browser-based tool to organize topics before psychotherapy sessions, with no accounts and no remote storage of responses.

**Highlights:** first-session and weekly preparation questionnaires (plus a five-question quick mode); optional free-text questions; editable review, topic ordering, and per-answer inclusion controls; local report preview and browser-based PDF printing; light/dark/system themes; an accessible guided tour; privacy information; automatic GitHub Pages deployment.

**Please note:** to save the report as a PDF, use your browser's **Print → Save as PDF** option; direct PDF download and native file sharing are not included yet. Nothing is sent automatically. Drafts are not saved across reloads. This alpha is intended for **fictional-data testing** and professional review before real-world clinical use.
